# خلاصه اجرایی  
برای تهیه فهرست جامعی از بازیگران ایرانی، باید منابع مختلف را بررسی کرد. منابع اصلی شامل ویکی‌پدیا (فارسی)، بانک‌های اطلاعات سینما (مانند «منظوم» و «هنرمان»)، سرویس‌های جهانی (IMDb) و فهرست‌های خصوصی (نمناک، ایران‌آکتور و غیره) می‌شوند. در جدول زیر این منابع مقایسه شده‌اند و در ادامه، ۵ منبع برتر تحلیل شده‌اند. همچنین روش ترکیب داده‌ها، مسائل حقوقی و نمونه کد و نمودار جریان داده ارائه می‌گردد.

## ۲. بررسی ۵ منبع برتر  

1. **منظوم (Manzoom):** بزرگ‌ترین بانک اطلاعات سینما و تلویزیون ایران است. قابلیت جستجو و فیلتر پیشرفته دارد و اطلاعات بازیگران (بیوگرافی، عکس، آثار و حواشی) را پوشش می‌دهد. ضعف: فاقد API رسمی است و استخراج داده نیازمند اسکرپینگ است که باید به محدودیت‌های سرور و قوانین سایت توجه شود. داده‌های آن غالباً قابل اعتماد و به‌روز هستند، چرا که علاوه بر منابع دولتی، کاربران نیز بررسی و ویرایش می‌کنند. استخراج حجمی با اسکرپینگ HTML یا بررسی درخواست‌های شبکه (network) در مرورگر قابل انجام است، ولی مستلزم رعایت **قوانین مالکیت محتوا** است.

2. **ویکی‌پدیا (فارسی):** فهرست بازیگران را به ترتیب حروف الفبا ارائه می‌دهد. مزیت: کاملاً رایگان، داده زیر مجوز CC BY-SA است و می‌توان با API ویکی‌پدیا به راحتی فهرست و لینک هر بازیگر را استخراج کرد. معایب: پوشش کامل نیست (وابسته به مشارکت کاربران) و اطلاعات معمولاً خلاصه است. در عین حال، هر بازیگر عمده در ویکی‌پدیا صفحه دارد که جزئیات زندگی‌نامه و آثار را می‌توان از آن‌ها جمع‌آوری کرد. روش استخراج: استفاده از Wikipedia API یا ایحاد ابزار پایتون برای فراخوانی صفحات و پردازش HTML/JSON.

3. **IMDb:** بانک اطلاعات فیلم و بازیگر بین‌المللی است. امکان فیلتر ملیت یا جستجو بازیگر ایرانی در نسخه وب یا IMDbPro وجود دارد. مزایا: پوشش جهانی و اطلاعات دقیق (فیلم‌شناسی کامل). معایب: داده‌ها تحت قوانین IMDb است، API رسمی پولی (IMDbPro) یا غیررسمی (مانند IMDbPY) باید استفاده شود. استخراج حجمی دشوار است (وب‌سایت دارای حفاظت دربرابر ربات است). با این حال، استفاده از دیتاست‌های باز مانند **OMDb API** یا دانلود دیتابیس خصوصی می‌تواند راهی باشد. اعتبارش بالاست اما باید به مجوز استفاده توجه شود (مشخصاً اطلاعات فیلم‌شناسی به عنوان داده عمومی قابل استفاده است).

4. **هنرمان:** بانک اطلاعات هنرمندان است که اعضا برای معرفی خود ثبت‌نام می‌کنند. مزیت: تمرکز بر هنرمندان ایرانی و ثبت‌نام خودکار آنها. معایب: پوشش وابسته به پر شدن پروفایل‌ها توسط خود هنرمندان یا مدیر سایت است؛ جستجو و فیلتر خیلی پیشرفته نیست. اسکرپینگ صفحه هنرمندان (لیست گروه‌های هنری و اعضا) ممکن است، اما هرچند اطلاعات رزومه و گالری تصویر هم ممکن است حقوق داشته باشد. سایت به‌روزرسانی ثابتی دارد ولی نشانی دقیق تعداد نفرات در دسترس نیست.

5. **نمناک (و فهرست‌های مشابه):** لیست‌های الفبایی مرتب بازیگران ایرانی با عکس است. مزیت: سریع و منظم برای دسترسی اسامی، دارای هر دو جنس. معایب: غیررسمی، ممکن است به‌روز نشود و هیچ فیلتری در آن نیست. استخراج دستی (دانلود HTML و استخراج نام‌ها) ممکن است، اما محتوا معمولاً پایدار نیست. به‌عنوان منبع اصلی اطلاعات توصیه نمی‌شود اما به‌عنوان تکمیل‌کننده یا چک‌لیست نام‌ها می‌تواند مفید باشد.

> **منابع تحلیلی:** یافته‌های بالا بر اساس بررسی صفحات رسمی این سرویس‌ها و گزارش‌های خبری مربوط است.

## ۳. پیشنهاد روش و ترکیب منابع  
هیچ منبع واحد کاملی وجود ندارد؛ ترکیب چند منبع بهترین راه است. پیشنهاد ما:  
- **استفاده ترکیبی از «منظوم» و «ویکی‌پدیا»:** منظوم به‌عنوان گسترده‌ترین بانک داده سینمای ایران با امکان جستجو و فیلتر پیشرفته، ویکی‌پدیا به‌عنوان منبع آزاد اطلاعات پایه (نام و تاریخ تولد).  
- **فرآیند ساخت لیست اصلی:**  
  1. استخراج نام بازیگران از ویکی‌پدیا (مثلاً فراخوانی کامل فهرست حروف الفبا) و از منظوم (جستجوی تکی برای هر حرف الفبا یا دریافت لیست هنرمندان ایرانی).  
  2. ترکیب داده: استفاده از پایتون و پانداس برای ادغام بر مبنای نام.  
  3. افزودن فیلدها: حداقل «نام و نام خانوادگی»، «جنسیت» (تفکیک از روی نام یا داده‌های دیگر)، «تاریخ تولد»، «آثار برجسته».  
  4. رفع تکراری‌ها: یکسان‌سازی املای نام‌ها (استانداردسازی حروف)، بررسی مشترکات ویکی‌پدیا و منظوم.  
  5. تگ‌گذاری جنسیت: اگر در داده مشخص نیست، با پایگاه نام فارسی یا API‌هایی مثل Gender API (ناپرس) تعیین (با توجه به حساسیت، برای بازیگران ابهام کمتر است).  
  6. تأیید صحت: تطبیق با منابع سوم مانند IMDb یا منابع رسمی سینمایی (کتابخانه ملی سینما یا خانه سینما) برای اطمینان.  
  7. به‌روزرسانی دوره‌ای: اجرای خودکار هر چند ماه (اسکریپت زمان‌بندی‌شده) برای بروز نگه‌داشتن فهرست.  

**داده‌های پیشنهادی:** نام (فارسی و لاتین)، جنسیت، تاریخ تولد، محل تولد، تعداد آثار (فیلم/سریال)، منابع تأیید، لینک پروفایل (در صورت وجود).  

## ۴. ملاحظات حقوقی و اخلاقی  
- **کپی‌رایت:** اطلاعات اساسی (نام و فیلم‌شناسی) از بازیگران در حوزه «حقایق» قرار می‌گیرد و مشمول حق کپی‌رایت نمی‌شود. اما شرح زندگی‌نامه و عکس‌ها ممکن است حقوق داشته باشند. استفاده از API یا منابع رسمی بهتر است. برای استخراج از سایت‌ها، شرایط استفاده (Terms of Service) را بررسی کنید؛ برخی سایت‌ها از اسکرپینگ صریحاً منع کرده‌اند.  
- **حریم خصوصی:** بازیگران و افراد مشهور اطلاعات عمومی خود را به اشتراک گذاشته‌اند. انتشار این داده‌ها (جزئیات عمومی) معمولاً مجاز است، اما به‌روزرسانی و تماس مستقیم با افراد مشروط به قوانین محلی است. برچسب‌گذاری اطلاعات باید اصول **قانون جرایم رایانه‌ای ایران** را رعایت کند (مثلاً اطلاعات حساس خصوصی را فاش نکنیم).  
- **رعایت قانون جمهوری اسلامی:** اطلاعات بازیگران ایرانی معمولاً رسانه‌ای است و اشکالی ندارد. اما در انتشار تصاویر و بیوگرافی تفصیلی باید مجوز داشته باشید. پیشنهاد می‌شود فقط فهرست اسامی و داده‌های غیرحساس را منتشر کنید.  

> **منابع حقوقی:** تحلیل حقوق نشر ایران و شرایط مجوز Creative Commons برای ویکی‌پدیا. اطلاعات عمومی در قوانین ایران آزاد است، به شرط احترام به حقوق مولف و مقررات حریم خصوصی.

# نمونه شبه‌کد (پایتون) برای دریافت نام بازیگران از ویکی‌پدیا (API)

for letter in list("ابپتثجچحخدذرزژسشصضطظعغفقکلمنوهی"):
    url = f"https://fa.wikipedia.org/w/api.php?action=query&list=categorymembers&cmtitle=Category:بازیگران_ایرانی&cmlimit=500&format=json"
    # در این مثال از یک دسته‌بندی فرضی استفاده شده است. در عمل ممکن است نیاز به ویکی‌دیتای واقعی یا جستجوی کلمه 'بازیگر'.
    res = requests.get(url)
    data = res.json()
    for item in data['query']['categorymembers']:
        actors.append(item['title'])
